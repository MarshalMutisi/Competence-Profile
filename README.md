# Competence-Profile

AI Career Competence Profile project, including market demand analysis spreadsheets and an interactive Next.js application presenting five remote AI job postings, skill gap analysis, and an 8-week learning plan.

## Project Structure

- `website/` - Next.js (App Router, TypeScript) web application
- `*.xlsx` - Job analysis and market demand spreadsheets

## Getting Started (Website)

Navigate to the `website` directory:

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
cd website
npm run build
```

The static site export will be generated in `website/out`.
